1. Finite Field Formulation: Galois Field \(GF(2^8)\)

All algebraic operations operate over the Galois Field \(GF(2^8) \cong \mathbb{F}_2[X] / (P(X))\) defined by the irreducible Rijndael polynomial:

$$P(X) = X^8 + X^4 + X^3 + X + 1 \quad (\text{hex: } 0\text{x}11\text{B})$$

Addition is XOR (\(\oplus\)). Constant-time multiplication utilizes Russian Peasant branchless reduction with bitmasks, eliminating timing variance and cache-collision vulnerabilities.

2. Shamir's Threshold Scheme & Information-Theoretic Security

To conceal a secret byte \(S \in GF(2^8)\), a random polynomial of degree \(k-1\) is constructed:

$$f(x) = S \oplus a_1 x \oplus a_2 x^2 \oplus \dots \oplus a_{k-1} x^{k-1}$$

Each share is an evaluation \((x_j, y_j) = (x_j, f(x_j))\) with \(x_j \neq 0\). Reconstructing \(S = f(0)\) requires \(k\) shares via Lagrange basis interpolation:

$$S = \bigoplus_{j=1}^k \left( y_j \otimes \ell_j(0) \right), \quad \ell_j(0) = \bigotimes_{m \neq j} \frac{x_m}{x_m \oplus x_j}$$

Theorem (Perfect Secrecy):

For any adversary observing \(k-1\) shares, for every candidate secret \(S' \in GF(2^8)\), there exists exactly one degree \(k-1\) polynomial passing through the observed points and \(S'\). Because random coefficients are uniformly distributed: $$\mathcal{I}(S; \text{Shares}_{k-1}) = 0 \implies \mathcal{H}(S \mid \text{Shares}_{k-1}) = \mathcal{H}(S)$$ The cloud host provider possesses zero mathematical knowledge of the master secret.
